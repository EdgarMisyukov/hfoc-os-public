Console font assets used by the HFOC 8x16 console glyph table
==================================================================

Source: Debian console-setup-linux, CyrSlav-Fixed16.psf.gz (PSF1 8x16),
byte-identical to /etc/console-setup/cached_CyrSlav-Fixed16.psf.gz.
Package: console-setup-linux. Extracted on 2026-11-17 by gen_font8x16.py.
Only the glyph pictures for ASCII, Cyrillic, and the listed punctuation
were converted; no font binary or PSF table is shipped.

All console fonts are public domain by nature.  The copiright terms of
the source BDF-fonts in the directory Fonts/bdf of the source package
follow.
