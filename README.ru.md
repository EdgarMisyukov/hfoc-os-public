# HFOC OS

[English](README.md) · Русский · [Официальный сайт](https://hfoc.ru/)

HFOC OS — операционная система для сетевых устройств на x86-64. В версии 1.0.0 доступны веб-панель на русском и английском языках, SSH по ключу владельца, нативная оболочка и сохраняемый рабочий каталог на HFOCFS.

- [Выпуск и поддержка оборудования](docs/release-1.0.0.ru.md)
- [Загрузка и способы установки](docs/install.ru.md)
- [Настройка, SSH и диагностика](docs/operate.ru.md)
- [Сборка загрузочного образа](docs/build.ru.md)
- [Лицензии и участие в проекте](docs/licensing.ru.md)

Общий загрузочный ISO для BIOS и UEFI, контрольные суммы и перечень компонентов SPDX доступны в [выпуске v1.0.0](https://github.com/EdgarMisyukov/hfoc-os-public/releases/tag/v1.0.0). В репозитории находятся публичный снимок исходников и руководства выпуска. Команды проверки и происхождение сборки описаны в [руководстве по сборке](docs/build.ru.md).

Выпуск собран из коммита `933f7cd739a9437e86638fbfe30a738e22f2e9aa`. Проверенная сборка на Toshiba L875 сообщает `933f7cd739a9`.

Код и документация HFOC распространяются по [GNU AGPL версии 3](LICENSE) либо по отдельной письменной коммерческой лицензии. Внешние компоненты сохраняют свои исходные лицензии.
