# HFOC OS

[English](README.md) · Русский

HFOC OS — операционная система для сетевых устройств на x86-64. В версии 1.0.0 доступны веб-панель на русском и английском языках, SSH по ключу владельца, нативная оболочка и сохраняемый рабочий каталог на HFOCFS.

- [Выпуск и поддержка оборудования](docs/release-1.0.0.ru.md)
- [Загрузка и способы установки](docs/install.ru.md)
- [Настройка, SSH и диагностика](docs/operate.ru.md)

В этой ветке доступны первые публичные руководства для версии 1.0.0. Снимок исходного кода и образы для скачивания готовятся к размещению в этом репозитории.
