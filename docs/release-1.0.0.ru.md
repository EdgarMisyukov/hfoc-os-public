# HFOC OS 1.0.0

[Главная](../README.ru.md) · [English](release-1.0.0.md) · Русский

Версия 1.0.0 — первый продуктовый выпуск. Нативное ядро предназначено для x86-64 и загружается через Limine в режимах BIOS и UEFI.

## Возможности

- В веб-панели можно настроить сетевой адрес, сертификаты HTTPS и маршруты HTTPS к указанному серверу. Интерфейс доступен на русском и английском языках.
- Владелец может подключиться к SSH по открытому ключу и запустить нативную оболочку с историей команд, редактированием UTF-8, конвейерами, перенаправлениями и управлением заданиями.
- Каталог `/home/owner` хранится на диске. Обновление с сохранением состояния переносит учётную запись, ключи SSH и файлы владельца.
- Снимок диагностики можно скачать по SSH и проверить по количеству записей и CRC.

## Проверки и ограничения

Две чистые сборки дали одинаковый релизный образ. В виртуальной машине проверены загрузка BIOS/UEFI, установка, SSH, оболочка и сохранение файлов. На Toshiba L875 с Ethernet RTL8168 проверены назначение адреса, вход в панель, SSH, маршрут HTTPS и сохранность файла после перезагрузки. Первый вход в панель в этом прогоне занял около 33 секунд. При сборе диагностики наблюдались краткие сбросы соединений. Повторные проверки прошли.

HFOC OS запускает нативные программы. Бинарная совместимость с Linux и полная поддержка POSIX выходят за рамки этого выпуска. Поддержка конкретной машины зависит от контроллера накопителя, сетевого адаптера и прошивки.

Исходный коммит выпуска `933f7cd739a9437e86638fbfe30a738e22f2e9aa`. Сборка `933f7cd739a9`.
