## English

### First-boot setup stages

The first-boot state machine validates an at-rest administrator credential record, hostname, network configuration, connectivity and persistence evidence in order. It publishes the management URL after validating readiness.

[Technical reference](../../hfoc-first-boot-wizard.md)

## Русский

### Этапы настройки при первом запуске

Автомат состояний первого запуска последовательно проверяет запись хранимых учётных данных администратора, имя узла, сетевые настройки, доступность сети и подтверждение записи настроек. Адрес управления публикуется после проверки готовности.
