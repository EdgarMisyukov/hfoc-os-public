# Загрузка и установка

[Главная](../README.ru.md) · [English](install.md) · Русский

HFOC OS загружается с образа BIOS или UEFI на машине x86-64. Для первого запуска используйте виртуальную машину, чтобы проверить консоль и сеть с отдельным виртуальным диском. Публичный комплект исходников и образов ещё готовится.

## Выбор режима установки

| Режим | Что происходит | Место под разделы HFOC |
| --- | --- | --- |
| Весь диск, UEFI | Разметка выбранного диска заменяется разметкой HFOC | 161 МиБ |
| Весь диск, Legacy BIOS | Разметка выбранного диска заменяется разметкой HFOC | 162 МиБ |
| Сохранение существующей системы | Установка в неразмеченную область на поддерживаемых системах с GPT и UEFI. Используется существующий системный раздел EFI | 128 МиБ |
| Обновление | Установленная HFOC OS обновляется с сохранением каталога владельца и настроек | Используется существующая разметка |

Цифры в таблице относятся к самим разделам. На диске также нужно место для таблицы разделов и выравнивания. Перед записью установщик сверяет заявленную идентичность диска и раскладку. Перед установкой на весь диск сохраните данные и проверьте, что выбран нужный накопитель.

Для двойной загрузки подготовьте неразмеченную область и оставьте существующий системный раздел EFI. Перед подтверждением убедитесь, что установщик распознал прежнюю систему и предложил план с её сохранением. Прежняя система может появиться в меню загрузки, когда обнаружена поддерживаемая запись UEFI.

После установки загрузитесь с установленного диска и откройте [руководство по первому запуску и управлению](operate.ru.md).
