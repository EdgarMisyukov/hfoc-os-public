# Загрузка и установка

[Главная](../README.ru.md) · [English](install.md) · Русский

HFOC OS загружается с образа BIOS или UEFI на машине x86-64. Скачайте общий ISO и `SHA256SUMS.txt` из [выпуска v1.0.0](https://github.com/EdgarMisyukov/hfoc-os-public/releases/tag/v1.0.0). Перед загрузкой сверьте SHA-256 образа с соответствующей строкой файла.

## Пробный запуск ISO в QEMU

Выполните команду из каталога с проверенным ISO. Она запускает общий загрузочный образ без подключения жёсткого диска. Для установки на диск формируется отдельный образ установщика с декларацией диска и режима разметки.

```sh
qemu-system-x86_64 -machine q35 -m 512M -cpu max,-apic \
  -cdrom hfoc-os-1.0.0.iso -serial stdio -no-reboot
```

## Выбор режима установки

| Режим | Что происходит | Место под разделы HFOC |
| --- | --- | --- |
| Весь диск, UEFI | Разметка выбранного диска заменяется разметкой HFOC | 161 МиБ |
| Весь диск, Legacy BIOS | Разметка выбранного диска заменяется разметкой HFOC | 162 МиБ |
| Сохранение существующей системы | Установка в неразмеченную область на поддерживаемых системах с GPT и UEFI. Используется существующий системный раздел EFI | 128 МиБ |
| Обновление | Установленная HFOC OS обновляется с сохранением каталога владельца и настроек | Используется существующая разметка |

Цифры в таблице относятся к самим разделам. На накопителе с логическим сектором 512 байт минимум для установки на весь диск с учётом служебных данных и выравнивания составляет 331 810 секторов для UEFI и 333 858 для Legacy BIOS. Перед записью установщик проверяет заявленный диск и раскладку. Перед установкой на весь диск сохраните данные и проверьте, что выбран нужный накопитель.

Для двойной загрузки подготовьте непрерывную выровненную неразмеченную область на диске GPT и сохраните его единственный системный раздел EFI. Перед подтверждением убедитесь, что установщик распознал прежнюю систему и предложил план с её сохранением. Прежняя система может появиться в меню загрузки, когда обнаружена поддерживаемая запись UEFI.

После установки загрузитесь с установленного диска и откройте [руководство по первому запуску и управлению](operate.ru.md).

Подготовка установщика, проверка плана разметки и проверка результата описаны в [подробном руководстве по установке и двойной загрузке](install-detail.ru.md).
