# Первый запуск и управление

[Главная](../README.ru.md) · [English](operate.md) · Русский

1. Если установщик оставил учётную запись владельца ненастроенной, завершите настройку командой `credentials` в локальной консоли. Войдите и узнайте адрес управления командой `network`.
2. Откройте HTTPS-панель по этому адресу из сети управления. Если используется самоподписанный сертификат, перед вводом учётных данных сверьте отпечаток сертификата с выводом локальной консоли.
3. В панели настройте DHCP или статический адрес. Сохраните изменения, перезагрузите систему и подключитесь по новому адресу. Для сертификата HTTPS на собственное имя настройте доступный источник времени и перед импортом убедитесь, что системные часы готовы.
4. Зарегистрируйте открытый ключ SSH-клиента. Сверьте ключ сервера с выводом `ssh-key show` в локальной консоли прежде, чем добавлять его в список известных хостов на клиенте. Для SSH используется ключ владельца, для панели — учётная запись.

Оболочка запускает нативные программы HFOC. Сохраняйте постоянные файлы в `/home/owner`. Каталоги `/tmp` и `/run` находятся в памяти.

Для получения снимка диагностики подставьте адрес управления вместо `HFOC_ADDRESS`. В `-i` укажите закрытый ключ владельца на клиенте, а в `UserKnownHostsFile` — файл с проверенным ключом сервера.

```sh
ssh -i ~/.ssh/hfoc_owner -o IdentitiesOnly=yes \
  -o UserKnownHostsFile="$HOME/.ssh/hfoc_known_hosts" \
  -o StrictHostKeyChecking=yes hfoc@HFOC_ADDRESS 'hfoc diag' > hfoc-diag.txt
```

Сохраните в отчёте идентификатор сборки, количество записей и CRC. Если сеть недоступна, команда `diag save` в локальной консоли позволяет записать снимок на диагностический носитель.
