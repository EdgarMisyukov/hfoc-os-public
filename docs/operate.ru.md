# Первый запуск и управление

[Главная](../README.ru.md) · [English](operate.md) · Русский

1. Завершите первичную настройку учётной записи владельца в локальной консоли. Войдите и узнайте адрес управления командой `network`.
2. Откройте HTTPS-панель по этому адресу из сети управления. Если используется самоподписанный сертификат, перед вводом учётных данных сверьте отпечаток сертификата с выводом локальной консоли.
3. В панели настройте DHCP или статический адрес. После смены адреса подключитесь по новому адресу. Для сертификата HTTPS на собственное имя настройте доступный источник времени и перед импортом убедитесь, что системные часы готовы.
4. Зарегистрируйте открытый ключ SSH-клиента и сверьте ключ хоста SSH с выводом локальной консоли. Подключитесь командой `ssh hfoc@HFOC_ADDRESS`, подставив вместо `HFOC_ADDRESS` адрес из вывода `network`. Для SSH используется ключ владельца, для панели — учётная запись.

Оболочка запускает нативные программы HFOC. Сохраняйте постоянные файлы в `/home/owner`. Каталоги `/tmp` и `/run` находятся в памяти.

Для получения снимка диагностики с другого компьютера выполните `ssh hfoc@HFOC_ADDRESS 'hfoc diag' > hfoc-diag.txt` с предварительно закреплённым ключом хоста. Сохраните в отчёте идентификатор сборки, количество записей и CRC. Если сеть недоступна, команда `diag save` в локальной консоли позволяет записать снимок на диагностический носитель.
