## Contributions

Discuss substantial changes before starting work. For implementation, use a feature branch and a Draft PR, keep the failing and passing regression evidence, and preserve the existing test gates. Identify all copied, generated, vendored or embedded third-party material with its source, version or commit, checksum and license. Preserve upstream notices.

External contributions require a signed contributor license agreement. External PRs may be reviewed and discussed while the agreement and acceptance process await professional legal review. A maintainer applies `cla: signed` only after retaining a signed acceptance record associated with the contributor's identity.

Report a reproducible bug through [GitHub Issues](https://github.com/EdgarMisyukov/hfoc-os-public/issues). Include the version, build ID, machine or VM configuration, and steps to reproduce. Remove credentials and personal data from any material you attach. For a security report use [mis@hfoc.ru](mailto:mis@hfoc.ru).
