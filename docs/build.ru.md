# Сборка HFOC OS

[Главная](../README.ru.md) · [English](build.md) · Русский

Выполняйте эти команды в Git-копии публичного тега `v1.0.0`.

Установите в Debian инструменты сборки, тестирования и создания ISO.

```sh
sudo apt-get install build-essential binutils curl ca-certificates file xorriso \
  qemu-system-x86 python3 shellcheck ccache
```

Загрузите закреплённую зависимость загрузчика, выполните проверки на хосте и соберите общий загрузочный образ.

```sh
make deps
make test-console-host test-production-install-media-host \
  test-appliance-production-static-boot-host
make iso
make test-console-history
```

Образ появится в `build/hfoc-os-1.0.0.iso`. Выполните `sha256sum -c build/hfoc-os-1.0.0.iso.sha256` из каталога исходников для проверки результата. Команда запуска в QEMU приведена в [обзоре установки](install.ru.md). Для установки на диск и обновления создаётся отдельный образ установщика с заявленным диском и раскладкой.

## Происхождение релиза

Выпуск 1.0.0 собран из коммита `933f7cd739a9437e86638fbfe30a738e22f2e9aa` с идентификатором `933f7cd739a9` и `SOURCE_DATE_EPOCH=1795545829`. SHA-256 опубликованного образа — `c903a2abaefe0f35b7924d6d01a123a618142fd7bb3087ee5b449c196750ed56`.

При проверке релиза образ собрали дважды, сравнили результаты и сформировали перечень компонентов SPDX. У публичного снимка свой идентификатор коммита. В его примерах и тестах используются условные идентификаторы устройств. Контрольная сумма локальной сборки может отличаться. Сверяйте скачанный ISO выпуска по `SHA256SUMS.txt`.

Сопровождающие выполнили полный `make check` в копии с оригинальной историей Git. Для проверки перехода с MIT нужны оригинальные коммиты. В публичной копии доступны перечисленные выше команды. [Происхождение исходников](../release/source-provenance-v1.0.0.txt).
